MIMO Communication Analysis Toolkit - Help

This document explains the toolkit architecture, MIMO channel model, the method used to compute MIMO OFDM channel capacity, the meaning of each user input, and how to interpret every output plot and file.

1) Toolkit Architecture

  • Input Channel Model: The toolkit imports a frequency-domain S-parameter sweep from an RST/RSP (HDF5) file. Each stored coefficient is the complex port-to-port transmission response from one transmit antenna element to one receive antenna element, over a swept frequency band, for one or more channel soundings, across a scenario time history.
  • Antenna Usage: Every transmit antenna and every receive antenna reported for the selected link is used. There is no per-antenna selection; the full MIMO array is analyzed as a single spatial channel matrix.
  • OFDM Waveform Assumption: The link is analyzed as an OFDM waveform using a user-selected 3GPP subcarrier spacing (SCS) and resource-block count. The imported frequency sweep is interpolated onto the exact OFDM subcarrier center frequencies.
  • Capacity Engine: For every OFDM subcarrier, the complex channel matrix is assembled and its equal-power Shannon capacity is computed. Subcarrier capacities are summed across the occupied bandwidth to produce total capacity for that time sample.
  • Time and Sounding History: Every scenario frame and every channel sounding within that frame is treated as a distinct, chronologically ordered time sample (frame-major, sounding-minor), so capacity is reported as a full time history rather than a single value.
  • Streaming for Large Files: The HDF5 response dataset is read one sounding and one antenna-port path at a time and interpolated immediately onto the OFDM grid. The full response array is never loaded into memory, which allows multi-gigabyte channel files to be processed safely.
  • Optional GPU Acceleration: When Use GPU is selected, the same batched linear-algebra operations run on a local NVIDIA GPU through CuPy instead of NumPy.

2) What Is MIMO?

MIMO (Multiple-Input, Multiple-Output) refers to a radio link that uses multiple antenna elements at both the transmitter and the receiver. Instead of a single scalar channel gain between one Tx and one Rx antenna, the link is described by a complex channel matrix that captures every antenna-to-antenna coupling simultaneously:

H(f) ∈ ℂNr × Nt,   where Nt is the number of transmit antenna ports and Nr is the number of receive antenna ports.

Each entry Hi,j(f) is the complex transmission coefficient from transmit port j to receive port i at frequency f, exactly as reported by the imported S-parameter sweep. When the propagation environment provides enough multipath richness and angular diversity, this matrix supports multiple independent spatial data streams at the same time, on the same frequency and time resource — this is spatial multiplexing, the core benefit of MIMO.

How much benefit is available depends on the channel's spatial structure: a channel dominated by a single strong path (for example, pure line-of-sight with little scattering) behaves close to rank-1 and offers little multiplexing gain, while a rich multipath channel (common in complex urban and indoor environments, including many non-line-of-sight conditions) can offer multiple usable spatial modes.

3) Method Used to Compute MIMO OFDM Channel Capacity

  1. Channel matrix per subcarrier: For every active OFDM subcarrier frequency, the imported frequency sweep is linearly interpolated (independently for the real and imaginary parts) onto that exact subcarrier frequency, for every Tx–Rx antenna pair, producing Hk for subcarrier k.
  2. Equal-power allocation: The user-specified total transmit power is divided equally across every active subcarrier and, on each subcarrier, equally across every transmit antenna port. This mirrors a realistic scheduler baseline rather than an idealized water-filling allocation.
  3. Per-subcarrier capacity: Using the Shannon/Telatar MIMO capacity expression,

    Ck = log2 det( I + γk Hk HkH )  (bits/s/Hz)

    where γk combines the per-port transmit power, the number of transmit ports, and the thermal noise power (from noise density and noise figure) on that subcarrier. The determinant is evaluated with a numerically stable log-determinant (slogdet) rather than an explicit eigenvalue product.
  4. Total capacity for one time sample:

    C = Δf ∑k Ck  (bits/s)

    where Δf is the selected subcarrier spacing and the sum runs over every active subcarrier in the configured resource-block allocation.
  5. Batched, memory-bounded evaluation: Subcarriers are processed in fixed-size batches so that only a small Gram matrix set is held in memory at any time, using whichever of H HH or HH H is smaller (an 8×32 uplink, for example, always forms the 8×8 Gram matrix rather than 32×32).
  6. Spatial diagnostics per subcarrier: The eigenvalues of the smaller Gram matrix are also used to compute the effective rank, condition number, and dominant eigenvalue fraction described in Section 5, and these are averaged across all active subcarriers for that time sample.
  7. Repeat over time: Steps 1–6 are repeated for every scenario frame and every channel sounding inside that frame, in chronological order, to build the full capacity and spatial-diagnostic time history.
Note: Because the imported S-parameters are treated as already including antenna gain and coupling effects from the input port of each transmit antenna to the output port of each receive antenna, no separate antenna-pattern or path-loss correction is applied. Capacity is computed directly at the RF reference ports represented in the imported file.

4) RST / RSP File Format (Channel Import)

The toolkit expects HDF5-based channel files with a /Links hierarchy, the same format used by the End to End Communication Analysis toolkit. After clicking Load Metadata, every link in the file is discovered and its Tx/Rx antenna counts, sounding count, sample count, sounding interval, bandwidth, and center frequency are displayed.

  • /Links/<Link>/Transmitter - Tx antenna metadata (antenna count and, when available, antenna names)
  • /Links/<Link>/Receiver - Rx antenna metadata (antenna count and, when available, antenna names)
  • /Links/<Link>/Waveform - bandwidth, center frequency, sample count, channel sounding count, sounding interval
  • /Links/<Link>/Channel Characterization/Response - frequency response for every Tx-Rx-sounding combination (real/imaginary interleaved)
  • /Links/<Link>/Channel Characterization/Time Array - frame time axis
Frame and sounding ordering: Each scenario frame may contain multiple channel soundings, taken at contiguous time steps within that frame. The toolkit processes every sounding of every frame, in order, and assigns each one a timestamp equal to the frame time plus sounding_index × Sounding Interval.
Large files: The full response dataset is never loaded into memory at once. If the file cannot be opened at all and the error mentions a truncated file or a stored end-of-file mismatch, the file itself is incomplete (for example, the simulation ran out of disk space while writing) and must be regenerated; this is not a toolkit memory limitation.

5) User Inputs - Technical Meaning and Theory

InputTechnical MeaningTheory / Practical Impact
LinkSelects which link from the imported RST/RSP file to analyze.Populated after Load Metadata. Every transmit and receive antenna reported for the selected link is used automatically; no per-antenna coupling is chosen.
Subcarrier Spacing (SCS)OFDM subcarrier frequency spacing, offered at the standard 3GPP NR values (15, 30, 60, 120, 240, 480, and 960 kHz).Sets Δf in the capacity summation. For a fixed occupied bandwidth and fixed transmit power spectral density, ideal Shannon capacity is largely insensitive to SCS; SCS mainly changes how many subcarriers span the same bandwidth and how finely the frequency-selective channel is sampled.
Resource BlocksNumber of 3GPP NR resource blocks used. Each resource block contains 12 subcarriers.Together with SCS this sets the occupied OFDM bandwidth (12 × Resource Blocks × SCS), which must not exceed the bandwidth of the imported channel file.
Total Tx PowerTotal radiated power across the entire transmit array, in dBm.Divided equally across every active subcarrier and, on each subcarrier, equally across every transmit antenna port. Higher power raises the per-subcarrier SNR and therefore capacity, with diminishing (logarithmic) returns.
Thermal Noise DensityReceiver noise power spectral density in dBm/Hz (a value near -174 dBm/Hz corresponds to standard room-temperature thermal noise).Combined with subcarrier spacing and noise figure to obtain the thermal noise power on each subcarrier at each receive port.
Receiver Noise FigureAdditional receiver noise contribution, in dB, on top of the thermal noise floor.Higher noise figure directly reduces per-subcarrier SNR and therefore reduces capacity; it does not change the channel's spatial structure (rank, condition number, dominant eigenvalue fraction).
Acceleration (Use CPU / Use GPU)Selects whether batched matrix operations run on the CPU with NumPy or on a local NVIDIA GPU with CuPy.Both paths compute the identical mathematical result. GPU mode requires the CuPy package matching the installed CUDA version and a CUDA-capable GPU; it is most beneficial for large antenna counts, wide bandwidths, or long scenario time histories.

6) Capacity Summary (Status and KPI Tab)

  • Mean Capacity: Average of the total OFDM capacity (C(t), converted to Gbps) across every processed time sample in the scenario.
  • Peak Capacity: The single highest instantaneous capacity observed across the scenario time history, typically corresponding to a time sample with strong, well-conditioned multipath coupling.
  • Mean Spectral Efficiency: Average, across time, of the per-subcarrier spectral efficiency (bits/s/Hz per subcarrier) averaged over the OFDM band. Multiplying this by the occupied bandwidth reproduces the total capacity.
  • Mean Effective Rank: Average, across time, of the entropy-based effective rank described in Section 7. This indicates how many spatial modes are typically usable, not merely how many are mathematically nonzero.

7) Output Plots and Files (Capacity Time History Tab)

After analysis completes, four time-history plots are displayed together and are also saved individually as PNG files in the local output/ folder, named mimo_<metric>_<link>.png. A companion CSV file, mimo_capacity_<link>.csv, records every time sample with its frame index, sounding index, and all metrics below.

Plot / ColumnWhat It RepresentsHow to Interpret
Capacity (capacity_bps) Total instantaneous OFDM channel capacity at that time sample, computed as described in Section 3. Higher values indicate a stronger, better-conditioned MIMO channel at the configured Tx power, noise figure, and OFDM bandwidth. Drops often align with reduced dominant eigenvalue fraction or lower effective rank, but can also simply reflect lower received signal power.
Effective Rank (effective_rank) Entropy-based spatial rank, reff = exp( -∑i pi ln pi ), where pi = λi / ∑j λj are the normalized eigenvalues of the channel Gram matrix, averaged over all active subcarriers. This measures how evenly the channel's spatial energy is distributed among independent modes, not merely how many singular values are nonzero. A value near the maximum possible (min(Nt, Nr)) means spatial energy is spread across many equally strong modes; a value near 1 means one mode dominates. It is scale-invariant: several equally weak modes can still report a high effective rank even when absolute capacity is low, so effective rank should be read together with the capacity plot, not in isolation.
Condition Number (condition_number) Ratio of the largest to the smallest singular value of the channel matrix (via the square root of the largest-to-smallest Gram-matrix eigenvalue ratio), averaged over all active subcarriers. A condition number near 1 indicates a well-balanced, orthogonal-like channel that is favorable for spatial multiplexing. A large condition number indicates that one or more spatial modes are much weaker than the strongest mode, which limits achievable multiplexing gain even if the channel is not fully rank-deficient. This plot uses a logarithmic y-axis when all values are positive because condition number can span several orders of magnitude.
Dominant Eigenvalue Fraction (dominant_eigenvalue_fraction) pmax = λmax / ∑i λi, the fraction of total channel energy carried by the single strongest spatial eigenmode, averaged over all active subcarriers. Values close to 1 mean the link is effectively behaving like a single dominant path (for example, a strong line-of-sight or a single strong specular reflection), so most capacity gain would need to come from a higher-order modulation or more power rather than spatial multiplexing. Lower values indicate that channel energy is shared among multiple modes, which is favorable for MIMO spatial multiplexing.
time_s, frame_index, sounding_index The chronological timestamp of the sample, and the originating scenario frame and channel sounding within that frame. Use these to correlate a capacity dip or rank change with a specific point in the movement scenario, or to re-inspect the corresponding channel frequency/delay behavior in the End to End Communication Analysis toolkit.
Non-line-of-sight behavior: A blocked or non-line-of-sight time sample does not automatically produce a low effective rank. Rich multipath from reflection and diffraction can create several spatial modes of comparable strength, sometimes yielding higher effective rank than a strong single-path line-of-sight condition — while typically also producing lower absolute capacity due to reduced received power. Always review capacity, effective rank, condition number, and dominant eigenvalue fraction together for a complete picture of channel behavior at any given time sample.
